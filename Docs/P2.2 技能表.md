## 你现在的【1】～【5】

来自当前 `PlayerCombatDriver` / `SkillDefine`：

| 槽位 | 类型 | 代码名 | 机制一句话 | 典型手感 |
|------|------|--------|------------|----------|
| **【1】** | Melee | Slash | 近战范围判定 + **自动锁最近敌** + 身体转向 | 卢迪克式贴脸平A |
| **【2】** | Hitscan | Rail | 沿朝向射线，**无飞行时间**，碰到即结算 | 激光 / 点射 |
| **【3】** | Projectile | Fireball | 实体弹体飞行，碰撞或到达才命中 | 火球 / 箭 |
| **【4】** | DelayedArea | Meteor | 先定落点，**延迟后**范围爆炸 | 陨石点名 |
| **【5】** | PersistentZone | FireZone | 地面（或空间）**持续存在**，进出/站桩跳伤 | 火圈 / 毒池 |

共用能力：**索敌**（近战自动锁）、击退、VFX。  
还没有一等公民：引导光束、冲刺、召唤物、附着、护盾治疗、多段连招状态机等。

## 覆盖情况：要不要补机制？

### 你【1】～【5】已经能盖住的

- 近战平A、大部分大剑/枪贴脸 → **【1】**  
- 弓箭、法球、炮击 → **【3】**  
- 落雷/陨石/天星式点名 → **【4】**  
- 火圈、风眼、岩脊、持续站场 → **【5】**  
- 少量「指哪打哪」激光 → **【2】**  

做 **类 Diablo + 少量原神弓/法**，这五类当**结算内核**够用。

### 建议补的（按优先级）

| 优先级 | 缺口机制 | 原神例子 | 为啥要补 |
|--------|----------|----------|----------|
| **P0** | **连段 / 技能状态机** | 迪卢克、胡桃E窗口 | 【1】只有单次斩，没有 1-2-3 与技能形态 |
| **P0** | **远程自动锁 +【3】** | 宵宫 | 你已定加【2】槽走远程，应用弹道不是射线 |
| **P1** | **Channel 引导光束** | 那维莱特 | 单次【2】模拟不像；要「按住 + 每 tick 射线 + 可转向」 |
| **P1** | **位移 / 冲刺技** | 绫华、克洛琳德 | ARPG 手感刚需，现在五类都是「打」不是「移」 |
| **P2** | **召唤物** | 菲谢尔、芙宁娜 | 和 Zone 不同，是实体 AI |
| **P2** | **标记 / 附着跳伤** | 纳西妲 | 先挂目标再跳伤，不是当场圈 |
| **P3** | **护盾 / 治疗** | 钟离、希格雯 | 生存与辅助轴，可后做 |
| **P3** | **场力（吸/推）** | 温迪 | 在【5】上加力场参数即可，不一定新类型 |

### 不太急着当新类型的

- 纯 FPS 准星点射：ARPG 主循环用得少，【2】留作激光/特殊技即可  
- 每种原神元素反应：那是规则层，不是第 6 种「命中形状」

## 总判

- **现在的 1～5 = 五种「命中/存在形态」**，做动作 ARPG 主干够。  
- **原神角色有一半能勉强映射，另一半卡在：连段状态、引导、位移、召唤、标记，而不是再多一个 DelayedArea。**  
- **建议补机制顺序：**  
  1）【1】连段 + 宵宫式【3】远程锁敌  
  2）Channel（那维）  
  3）Dash/位移  
  4）召唤 / 标记
