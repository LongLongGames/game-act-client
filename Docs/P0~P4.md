根据仓库当前状态（README 开发计划 + `Docs/README_LES.md` + 近期 commits + 传输层文档），目前大致处于 **Phase 1 尾声 → Phase 2 入口**：

- Phase 0 骨架（登录、JWT、资料、基础场景/UI）已落地  
- LES（LiteEntitySystem）Solo / Host / Client 主路径已通，玩家移动 + 基础敌人已跑起来  
- Steam Lobby、LiteNet UDP 已接，Steam P2P 有现成 Patch 文档但未完全合入主路径  
- 战斗核心（伤害/技能/预测回滚/AOI）还没做  

下面给出 **接下去的开发计划（P0 ~ P4）**，按「能跑通核心体验 → 可联机打怪 → 可发布打磨」排序，并与服务器仓库对齐。

---

### P0（立刻做，1~2 周）—— 联机可玩的最小闭环
目标：**双人（或单机）能稳定移动 + 看到敌人 + 基础伤害，手感可接受。**

| 任务 | 说明 | 依赖/注意 |
|------|------|-----------|
| Client 本地预测手感打磨 | HumanController 已接，实机调缓冲/插值，消除明显抖动 | 参考 LES 未完成项 |
| 本机 `SimulateLatency` + 双进程回归 | 验证预测/回滚在延迟下不崩 | 先用 UDP |
| 战斗最小集：伤害 + 受击 + 简单技能 RPC | 写在 Shared（`ActPlayer` / `ActEnemy` / RPC），禁止再开 LocalSimulation 分叉 | 权威在 ServerEntityManager |
| 投射物 `AddPredictedEntity`（可选最小版） | 先做 1~2 种技能投射物 | - |
| 断线/版本不一致基础 UI | typesHash 不匹配直接提示 + 重连入口 | 现有 Join 校验已有 |

验收标准：
- Solo：Map1 移动正常，能打红胶囊怪
- Host + Client：两人同屏，互相看见，能互相/打怪造成伤害

---

### P1（紧接着，2~3 周）—— 真正可用的联机传输 + 稳定性
目标：**Steam 环境下可开房邀请好友，或连官服/社区 VPS。**

| 任务 | 说明 |
|------|------|
| 合入 Steam P2P Transport（`PATCH_SteamP2P.md`） | 双传输（UDP / SteamP2P），Lobby 写 `les_transport` / `les_steamid` |
| Dedicated 路径打通 | `LesServerHost` + `LesDedicatedBootstrap` + `LesLauncherConnect`，与 Gateway 返回的 `lesHost/lesPort` 对接 |
| 断线重连完善 | 重连后实体状态恢复、房间内重进 |
| 物理命中 + LagCompensation 基础版 | 保证伤害判定在延迟下可接受 |
| 单机剧情进度上报 | 通关/解锁上报 game-act-server |

验收标准：
- Steam 双开：A 建房 → B 加入 → 能打怪
- 无 Steam 时回退 UDP 仍可用
- Launcher 命令行 `-lesConnect host:port` 可进 Dedicated

---

### P2（4~6 周）—— 战斗核心（对应 README Phase 2）
目标：**具备 Action RPG 的核心战斗循环。**

| 任务 | 说明 |
|------|------|
| 完整技能系统 + 客户端表现 | 技能表（ExcelConfigCompiler）、动画、特效、冷却 |
| 玩家完整预测 / 回滚 | 移动 + 技能释放 + 受击 |
| AOI / SyncGroup 分层 | 近景精确同步，远景怪群客户端群演（怪物不做回滚） |
| Boss / 普通怪基础 AI 与表现 | 服务器权威 AI，客户端只做表现 |
| 基础 HUD / 战斗 UI 完善 | 血条、技能栏、伤害数字等 |

验收标准：
- 1~4 人可一起刷一局完整战斗流程
- 远景怪数量上来后帧率仍可接受

---
