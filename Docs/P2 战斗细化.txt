**P2 战斗核心详细任务规划**

技术栈已定，下面按「① 算法/基础能力」和「② 使用场景」拆分，并标出可复用关系。整体按优先级排序，尽量让每一阶段结束后都有可玩的增量。

---

### 阶段划分总览（建议 5~6 周）

| 阶段 | 主题 | 主要产出 | 预计 |
|------|------|----------|------|
| P2-1 | 空间与查询基础 | 统一空间能力可用 | 1 周 |
| P2-2 | 技能命中最小闭环 | 能放技能、能打死怪 | 1~1.5 周 |
| P2-3 | 怪物移动与基础 AI | 怪会追、会攻击、不重叠 | 1 周 |
| P2-4 | 群体与绕障进阶 | Flow Field + 绕柱 + 仇恨 | 1 周 |
| P2-5 | AOI / 同步 / 特殊群 | 网络友好 + 高密度蜂群 | 1 周 |
| P2-6 | 打磨与扩展技能类型 | 完整技能库 + 手感 | 持续 |

---

### P2-1  空间与查询基础（最优先）

**① 算法/基础能力**
- [ ] `ISpatialIndex` 接口定义（Insert / Remove / Update / QueryRadius / QueryAABB / Raycast 占位）
- [ ] Spatial Hash 最简实现（支持 Layer：Ground / LowAerial）
- [ ] 分区（Section）管理器骨架（单 Section 先跑通，多 Section 预留）
- [ ] 基础 AABB / Sphere 查询工具

**② 使用场景**
- [ ] 实体注册/注销到空间（玩家、怪物）
- [ ] 简单范围查询测试（Debug 画出结果）

**可复用**：后续所有技能、AI、AOI、避障全部依赖此层。

---

### P2-2  技能命中最小闭环

**① 算法/基础能力**
- [ ] 技能执行器接口 `ISkillExecutor`
- [ ] 即时命中（Hitscan）检测
- [ ] 投射物基础（直线 + 简单碰撞）
- [ ] 伤害流水线（计算 → 结算 → 同步占位）
- [ ] 简单 Lag Compensation 占位（先记录位置历史）

**② 使用场景**
- [ ] 玩家释放即时技能打怪
- [ ] 玩家释放投射物打怪
- [ ] 怪物死亡、受击反馈（最简）
- [ ] 技能配置表读取（Excel → 运行时）

**可复用**：伤害流水线和技能执行器后续所有技能类型共用。

---

### P2-3  怪物移动与基础 AI

**① 算法/基础能力**
- [ ] 简单追击移动（直线或 NavMesh）
- [ ] Local Avoidance 最简版（分离力 Separation）
- [ ] 基础 FSM（Idle → Chase → Attack → Return）
- [ ] 仇恨/威胁值基础结构

**② 使用场景**
- [ ] 地面近战怪追玩家并攻击
- [ ] 少量悬浮射击怪（Wisp 类）瞄准射击
- [ ] 怪物之间不严重重叠
- [ ] 单机 + 联机下移动同步验证

**可复用**：FSM 和仇恨结构后续所有 AI 复用；Local Avoidance 后续群体直接用。

---

### P2-4  群体与绕障进阶

**① 算法/基础能力**
- [ ] Flow Field 生成与查询（基于 Spatial Hash 格子）
- [ ] Flow Field 动态更新（目标移动时）
- [ ] Local Avoidance 完善（加入障碍避让）
- [ ] 静态障碍写入 Flow Field

**② 使用场景**
- [ ] 中小规模地面虫群追玩家
- [ ] 虫群绕柱 / 绕障碍自然分流
- [ ] 仇恨切换时群体转向
- [ ] 攻击建筑型目标（限时清理预研）

**可复用**：Flow Field 可服务所有需要群体移动的场景。

---

### P2-5  AOI / 同步 / 特殊群

**① 算法/基础能力**
- [ ] 基于 Spatial Hash 的 AOI 分层（近/中/远）
- [ ] 高密度蜂群专用层（纯客户端群演接口）
- [ ] Section 跨区实体迁移
- [ ] 网络同步过滤（只同步 AOI 内实体）

**② 使用场景**
- [ ] 远景怪群纯客户端表现
- [ ] 建筑污染型蜂群（只打建筑 + 限时清理）
- [ ] 多 Section 长条地图基础跑通
- [ ] 联机下 AOI 正确性验证

---

### P2-6  技能类型扩展与打磨（可并行/持续）

**① 算法补充**
- [ ] 延迟生效技能（预警圈 + 定时触发）
- [ ] 固定区域持续（Ground AoE / DoT）
- [ ] 扇形 / 锥形 / 环形过滤
- [ ] 投射物预测生成（`AddPredictedEntity`）

**② 使用场景**
- [ ] 完整技能库配置与释放
- [ ] Boss 技能表现
- [ ] 受击、击退、硬直反馈完善
- [ ] 手感调优（预测缓冲、动画匹配）

---

### 任务依赖与并行建议

```
P2-1 空间基础
    ↓
P2-2 技能命中  ←→  P2-3 基础移动AI（可少量并行）
    ↓
P2-4 群体绕障
    ↓
P2-5 AOI与特殊群
    ↓
P2-6 扩展打磨（可持续）
```

- P2-1 必须最先完成。
- P2-2 和 P2-3 在空间基础完成后可部分并行。
- Flow Field（P2-4）等 Local Avoidance 和基础追击稳定后再上。
- 高密度蜂群和多 Section 放到中后期，避免过早复杂化。
